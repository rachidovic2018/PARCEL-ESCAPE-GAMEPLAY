# Installation

Copy the `.claude` folder into the root of the Parcel Escape Unity repository.

Expected layout:

```text
Parcel-Escape/
├── CLAUDE.md
├── PROJECT_STATE.md
├── Assets/
├── Packages/
├── ProjectSettings/
└── .claude/
    ├── AGENTS.md
    └── agents/
        ├── 01-technical-director.md
        ├── 02-core-gameplay-engineer.md
        ├── 03-unity-gameplay-engineer.md
        ├── 04-puzzle-level-designer.md
        ├── 05-solver-engineer.md
        ├── 06-mobile-ux-designer.md
        ├── 07-technical-art-director.md
        ├── 08-android-performance-engineer.md
        ├── 09-monetization-economy-designer.md
        └── 10-qa-release-engineer.md
```

Do not replace the repository-root `CLAUDE.md` with any individual agent file.
